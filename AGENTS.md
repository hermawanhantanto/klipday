# Agent Rules

## Documentation lookup with Context7

- Before taking any action that involves a library, framework, or API (writing code, editing configuration, upgrading dependencies, debugging), always query Context7 first to get the latest official documentation.
- Resolve the library ID with the Context7 `resolve-library-id` tool, then fetch the relevant docs with the Context7 docs query tool.
- Every action must align with the latest **stable** version documented by Context7 — never rely on memorized or potentially outdated API usage when Context7 has newer information.
